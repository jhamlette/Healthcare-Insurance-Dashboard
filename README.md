# 🏥 Healthcare Insurance Cost Dashboard

An interactive **Power BI dashboard** exploring how personal attributes and lifestyle factors affect **medical insurance charges**.

---

## 📊 1) Overview
This project visualizes relationships between **age, BMI, region, smoking status, and healthcare charges** using the Kaggle “Medical Insurance” dataset.  
Data was cleaned and prepared in **Python (Jupyter Notebook)**, then visualized in **Power BI Service** to uncover cost patterns across demographics and behaviors.

## 🎨 3) Dashboard Design
**Title:** *Healthcare Insurance Cost Dashboard*  
**Subtitle:** *Exploring patterns and lifestyle factors influencing insurance charges*

### KPIs
- Average Charges ($)
- Average BMI
- Total Patients

### Visuals
| Visual Type | Purpose |
|--------------|----------|
| **Donut Chart** | Smoker vs Non-Smoker Distribution |
| **Tree Map** | Regional Share by Smoker Status |
| **Scatter Plot** | Age vs Charges by Smoker Status |
| **Cards** | High-level summary metrics |

🎨 **Theme:** White canvas with teal, orange, and blue highlights  
🖼️ **Layout:** Clean header → KPI row → visual grid → footer  

---

## 💡 4) Insights
- **Smokers** show significantly higher average insurance charges.  
- **BMI** averages around 30.7, suggesting most patients fall in the overweight range.  
- **Southeast** region contains the largest share of smokers.  
- Clear correlation between **age** and **charges** — costs rise with age, especially for smokers.
